# Сервис формирования меню на неделю

Консольное приложение для составления меню на неделю:
подбор блюд по дням, учёт калорийности и сохранение меню.

## Возможности

- просмотр и поиск блюд;
- отбор блюд по калорийности и сортировка;
- добавление новых блюд;
- добавление блюд в меню на выбранный день (одно блюдо нельзя
  добавить в один день дважды);
- проверка калорийности дня относительно лимита;
- проверка заполненности дней недели;
- удаление блюда из меню;
- сохранение и загрузка данных в JSON.

## Структура проекта

- `main.py` — точка запуска, меню приложения;
- `dishes.py` — работа с блюдами;
- `menu.py` — работа с меню на неделю;
- `storage.py` — сохранение и загрузка данных (JSON);
- `utils.py` — вспомогательные функции (даты, безопасный ввод);
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных

`data/dishes.json` — список блюд:

```json
{"id": 1, "name": "Овсяная каша с ягодами", "calories": 320,
 "dish_type": "завтрак"}
```

`data/menu.json` — записи меню (блюдо на дату):

```json
{"id": 1, "dish_id": 1, "menu_date": "2026-09-14"}
```

В памяти блюда хранятся словарём `{id: данные}`, меню — списком
словарей. Классы на этом этапе не используются.

## Требования

- Python 3.x;
- pytest;
- flake8.

