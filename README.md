# Сервис формирования меню на неделю

## Назначение
Приложение помогает пользователю составить меню на неделю: 
подобрать блюда по дням, проверить калорийность и получить 
готовый план питания.

## Целевая аудитория
Люди, которые следят за питанием, планируют бюджет и хотят 
организовать домашнее меню на неделю.

## Предметная область
Планирование ежедневного рациона: блюда, их калорийность, 
распределение по дням недели и формирование итогового меню.

## Основные сущности
- Пользователь
- Меню
- Блюдо
- День

## Основные функции
- Добавление блюда в меню на выбранный день
- Расчёт суммарной калорийности дня
- Проверка, что на каждый день недели назначено хотя бы одно блюдо
- Формирование итогового меню на неделю

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
